Pydantic Models

Pydantic is a Python library used by FastAPI for data validation, serialization, and type checking. It ensures that the data received from the client is valid before processing the request.

1.BaseModel

BaseModel is the base class provided by Pydantic. It is used to define the structure of request and response data. 
mysite/main.py


from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Product(BaseModel):
    id: int
    name: str
    price: float

@app.post("/product")
def create_product(product: Product):
    return product

2.Field Validation

Field() is used to add validation rules such as minimum length, maximum length, default values, descriptions, and numeric limits. 
mysite/main.py


from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class Product(BaseModel):
    id: int
    name: str = Field(min_length=3, max_length=20)
    price: float = Field(gt=0)

@app.post("/product")
def create_product(product: Product):
    return product

3.JSONResponse

JSONResponse is used to send a custom JSON response with a specific status code. 

mysite/main.py


from fastapi import FastAPI
from fastapi.responses import JSONResponse

app = FastAPI()

@app.get("/message")
def get_message():
    return JSONResponse(
        content={"message": "Product Added Successfully"},
        status_code=201
    )

4.HTMLResponse

HTMLResponse is used to return HTML content instead of JSON. 

mysite/main.py



from fastapi import FastAPI
from fastapi.responses import HTMLResponse

app = FastAPI()

@app.get("/", response_class=HTMLResponse)
def home():
    return """

<html>
  <body>
    <h1>Welcome to FastAPI</h1>    
  </body>
</html>
    	"""

5.FileResponse

FileResponse is used to send a file (PDF, image, text, etc.) from the server to the client. 

mysite/main.py

from fastapi import FastAPI
from fastapi.responses import FileResponse

app = FastAPI()

@app.get("/download")
def download_file():
    return FileResponse("sample.pdf")
