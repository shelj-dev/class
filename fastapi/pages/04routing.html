Routing

Routing is the process of definingURL paths (endpoints)and specifying which function hould handle a client's request. FastAPI uses decorators like @app.get(), @app.post(), @app.put(), @app.Delete().

Create a products

mysite/main.py


from models import Product

products=[
    Product(id=1,name="phone",description="Buget phone"),
    Product(id=2,name="laptop",description="Buget laptop"),
    Product(id=3,name="pen",description="a black pen"),
    Product(id=4,name="table",description="A wooden table"),
]

@app.get("/products")
def get_all_products():
    return products
Create models.py,
mysite/models.py


from pydantic import BaseModel

class Product(BaseModel):
    id:int
    name:str
    description:str
    price:float
    quantity:int

1.GET Request

A GET request is used to retrieve data from the server. It does not modify any data.

create GET main.py,
mysite/main.py

.....

@app.get("/products/{id}")
def get_all_product_by_id(id:int):
    for product in products:
        if product.id==id:
            return product
    return "not found"

Output

2.POST Request

A POST request is used to create new data on the server.

Add POST main.py,
mysite/main.py

.....

@app.post("/products")
def add_product(product:Product):
    products.append(product)
    return product

Output

3.PUT Request

A PUT request is used to replace an entire existing resource.

Update PUT main.py,
mysite/main.py

.....

@app.put("/product")
def update_product(id: int, product: Product):
    for i in range(len(products)):
        if products[i].id == id:
            products[i] = product
            return "Product Updated Successfully"

Output

5.Delete Request

The DELETE method is used to remove data from the server.

Delete main.py,
mysite/main.py

.....

@app.delete("/product")
def delete_product(id: int):
    for i in range(len(products)):
        if products[i].id == id:
            del products[i]
            return "Product Deleted Successfully"

    return "Product not found"

Output

Path Parameters

Path Parameters are values that are included directly in the URL path. They are used to identify a specific resource, such as a product, student, or user.

path main.py,
mysite/main.py

.....

@app.get("/product/{id}")
def get_product(id: int):
    return {"Product ID": id}

Quary Parameters

Query Parameters are values passed after the ? symbol in the URL. They are commonly used for searching, filtering, sorting, and pagination.

Quary main.py,
mysite/main.py

.....

@app.get("/search")
def search_product(name: str, price: int):
    return {
        "name": name,
        "price": price
    }

Request Headers

Request Headers are additional pieces of information sent by the client along with an HTTP request. They provide details such as the content type, authentication token, browser information, and language.
