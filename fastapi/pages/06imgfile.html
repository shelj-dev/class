Image/File Upload and Static File Serving

FastAPI provides UploadFile for receiving files such as images. The uploaded image can be saved inside an uploads folder and then served using StaticFiles.

Step 1: Create Upload Folder

mysite/main.py

import os
import shutil

UPLOAD_DIR = "uploads"

if not os.path.exists(UPLOAD_DIR):
    os.makedirs(UPLOAD_DIR)
The uploads folder will contain all uploaded images/files.

Step 2: Configure Static File Serving

mysite/main.py

from fastapi.staticfiles import StaticFiles

app.mount(
    "/files",
    StaticFiles(directory=UPLOAD_DIR),
    name="files"
)
Files inside the uploads folder can now be accessed using:

http://127.0.0.1:8000/files/filename.jpg

Step 3: Create Image Upload API

mysite/main.py

from fastapi import UploadFile, File, HTTPException

@app.post("/upload")
def upload_file(file: UploadFile = File(...)):

    filename = file.filename

    if not filename:
        raise HTTPException(
            status_code=400,
            detail="File not selected"
        )

    file_path = os.path.join(
        UPLOAD_DIR,
        filename
    )

    with open(file_path, "wb") as buffer:
        shutil.copyfileobj(
            file.file,
            buffer
        )

    return {
        "message": "File Uploaded Successfully",
        "fileName": filename,
        "file_url": f"http://127.0.0.1:8000/files/{filename}"
    }

Step 5: Image URL

Response

{
    "message": "File Uploaded Successfully",
    "fileName": "product.jpg",
    "file_url": "http://127.0.0.1:8000/files/product.jpg"
}
The returned file_url can be stored in the database and later used to display the product image.

Step 6: Store Image URL in Product Database

mysite/schemas.py

from pydantic import BaseModel

class ProductCreate(BaseModel):

    name: str
    description: str
    image: str

    class Config:
        from_attributes = True

mysite/models.py

from sqlalchemy import Column, Integer, String
from database import Base

class Products(Base):

    __tablename__ = "products"

    id = Column(Integer, primary_key=True, index=True)
    name = Column(String)
    description = Column(String)
    image = Column(String)

Step 7: Add Product With Image URL

mysite/main.py

@app.post("/products/db")
def add_product_db(
    product: ProductCreate,
    db: Session = Depends(get_db)
):

    new_product = Products(
        name=product.name,
        description=product.description,
        image=product.image
    )

    db.add(new_product)
    db.commit()
    db.refresh(new_product)

    return {
        "message": "Product Added Successfully",
        "data": new_product
    }

FastAPI UploadFile

StaticFiles
  ↓
/files/product.jpg
  ↓
Image URL
  ↓
Product.image
  ↓
SQLite Database

Important Note

Do not create another route such as @app.get("/files/{filename}"). The following mount already handles file access: 
mysite/main.py

app.mount(
    "/files",
    StaticFiles(directory=UPLOAD_DIR),
    name="files"
)
Therefore:

uploads/product.jpg
becomes
http://127.0.0.1:8000/files/product.jpg
